# Originals

Put your own photographs here. Only images you took or hold clear rights to.

Naming: `<type>_<slug>.jpg` where type is one of
`portrait`, `street`, `landscape`, `text`, `abstract`. Example: `street_brick_lane_01.jpg`.
The type prefix is what experiment 4 (photo types) groups by.

Consent: do not add images of identifiable people unless they have agreed to the
image being processed by third-party AI services and possibly published on the
project website. Images that must stay private can be listed in `private.txt`
(one filename per line); they are processed but excluded from the web export.

Photos in this folder are committed to the public repo, so cloud sessions keep them.
Photos that must stay private go in `data/originals/private/`, which is never committed.
